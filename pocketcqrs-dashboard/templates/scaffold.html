Scaffold a slice

describe → generate → dry run → save
This writes nothing. It generates a decider and a projection from what you describe, dry-runs them against the live log, and shows you the result — then you open each file in the editor to save it. Generated code takes exactly the same path as hand-written code. {{if .Flash.Text}} {{.Flash.Text}} {{end}} {{/* A plain form: this is a description being filled in, not a live surface, and it must survive a refused generate with what was typed intact. */}}

The aggregate

The stream family every command in this slice writes to. One stream per instance, identified by the id in the command URL.

Commands and their events

Each command records exactly one event — the common case, and the one worth generating. Mark the create: the generated decider refuses it on a stream that already exists, and refuses every other command on one that does not.
